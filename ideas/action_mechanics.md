# アクションメカニクス詳解：ZERO_HOUR

## 1. コマンド・チェーン (Command Chain)
複数のPLが連続してコマンドを成功させることで発動する強力なアクション。

| チェーン名         | 構成アクション (順番)                             | 効果                                                 |
| :----------------- | :------------------------------------------------ | :--------------------------------------------------- |
| **Emergency Sync** | PL1: `sync` -> PL2: `sync` -> PL3: `sync`         | 全サーバーの時刻同期を強制。15分間の「猶予」を獲得。 |
| **Trace Back**     | PL_A: `sniff` -> PL_B: `resolve` -> PL_C: `track` | 攻撃者のIPを特定。流出スコアを一時停止。             |
| **Holy Shield**    | 全員: `auth` (同時入力)                           | 1分間の無敵状態。あらゆる攻撃を無効化。              |

## 2. リアルタイム・イベント (Active Time Event)
ゲーム中、突如Web画面に巨大な注意報が表示されるアクション要素。

- **「Brute Force 進行中！」**:
    - 30秒以内に、全PLがランダムに表示される「6桁の英数字」をターミナルに入力し終えなければならない。
    - 失敗：ランダムに一人のアカウントがロック（15分間行動不能）される。
- **「Data Wipe 開始！」**:
    - 画面中央にプログレスバーが出現。`cancel --force` を誰よりも早く打った人がヒーローになれる。

## 3. ロール別「操作感」の差別化
- **SRE**: コマンドの文字数が少なく、高速に打てる。
- **Forensics**: ログの出力が非常に長く、そこから「特定のキーワード」を `grep` する技術が問われる。
- **Admin**: 強力な権限を持つが、1回の# アクションメカニクス：タップ＆ダッシュボード

スマホ・タブレット参加者が「タップ」だけでプロ級の操作を行えるメカニクスです。

## 1. アクションパネル (UI/UX)
画面下部に **「3つのスロット（AP）」** が表示され、ボタンを押すたびに埋まっていく直感的なUI。

- **[調査] カテゴリ**: `スキャン`, `監査`, `通信追跡`
- **[防御] カテゴリ**: `アカウント凍結`, `パッチ適用`, `接続切断`
- **[ハッカー専用]**: 表向きは上記のボタンに見えるが、長押しや裏メニューで `データ抽出` や `ログ改ざん` が出現。

## 2. スマホ特有の演出
- **ハッキング通知**: 自分が攻撃されている際、スマホが不規則に振動（バイブ）する。
- **緊急回避**: 画面に「WARNING!」が出た際、指定された場所を5秒間連打（連打アクション）して攻撃を防ぐ。
- **密談通知**: 非公開メッセージが届くと、画面端が青く光る。
