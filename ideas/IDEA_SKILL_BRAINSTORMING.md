# 社員スキル対応表 (1AP & 2AP 確定版)

各役割に「低コスト(1AP)」と「必殺技(2AP)」の2種類を割り当てた一覧表です。
また、全プレイヤー共通のシステムとして「議論フェーズでの投票」が存在し、最多得票者は次ターン -3AP のペナルティを受けます。

| 役割名                                        | 1 AP スキル (汎用・調査・遅延)             | 効果                                                                                                            | 2 AP スキル (必殺・防御・逆転)      | 効果                                                                                                  |
| :-------------------------------------------- | :----------------------------------------- | :-------------------------------------------------------------------------------------------------------------- | :---------------------------------- | :---------------------------------------------------------------------------------------------------- |
| **ネットワーク管理者**<br>(Network Admin)     | **ログ追跡**<br>`TRACE_LOG`                | 指定した対象の「現ターンのハッカー行動」の有無(白/黒)を調査する。(偽装対象も黒)                                 | **通信遮断**<br>`IP_BLOCK`          | 指定した対象1名の、次のターンの**すべてのアクション**を無効化する。                                   |
| **セキュリティ分析官**<br>(Security Analyst)  | **セキュリティパッチ**<br>`PATCH`          | **事前にプレイヤーを選択**し、そのターンに指定した味方1名への「AP減少デバフ(DDOS/ロックアウト)」を無効化する。  | **ファイアウォール**<br>`FIREWALL`  | 次ターン、システムへの「HPダメージ」と「LEAK進行」、ロックアウトを**最初の1回だけ**完全に無効化する。 |
| **DBエンジニア**<br>(Database Engineer)       | **データマスキング**<br>`MASKING`          | **次ターンのLEAK発生時**、一度だけ漏洩量を **-5%** 軽減する。                                                   | **ハニーポット**<br>`HONEY_POT`     | 罠を張る。次ターン「データ持ち出し(EXFIL)」を行った実行者の名前を検知する。                           |
| **システムオペレーター**<br>(System Operator) | **リソース・デプロイメント**<br>`TRANSFER` | 指定した味方1名の次ターンのAPを **+1** チャージする。 **(1ターンに1回のみ)**                                    | **システム・リストア**<br>`RESTORE` | そのターン中、**HPが0になった際に自動で20回復**して復活する。                                         |
| **インフラリーダー**<br>(Infra Lead)          | **レプリケーション**<br>`SKILL_COPY`       | 他プレイヤーのロール固有1APスキルを**ランダムに1つコピー**し、そのターンのみ使用可能にする。                    | **スペックアップ**<br>`SPEC_UP`     | システムのHP上限を **120** に拡張する(持続2ターン)。                                                  |
| **DevOps**<br>(Development & Operations)      | **CI/CDパイプライン**<br>`PIPELINE`        | **自分を含む**指定した対象1名を選択。対象がそのターンに証拠解析を行うとBOT効率が向上(**BOT1台あたり+2%追加**)。 | **解析ボット配備**<br>`DEPLOY_BOT`  | 自動解析ボットを設置(最大3台)。**1ターン1回まで。**<br>ターン終了時に **Analysis +3%** 加算。         |

# スキル検証チェックリスト

全スキルの動作が仕様通りか、以下の項目に従って検証を行います。

## 1. 共通アクション

- [〇] **証拠解析 (ANALYZE_EVIDENCE)**: 解析率が上昇するか。
- [〇] **システム修復 (RESTORE_SYSTEM)**: システムHPが+10回復するか。
- [〇] **データ暗号化 (ENCRYPT_DATA)**: 漏洩率が-10%減少するか。
- [〇] **監査ログ参照 (VIEW_AUDIT_LOG)**: 前ターンのハッカー行動数が実行者にのみ通知されるか。
- [〇] **投票 (VOTE)**: 議論フェーズ中に投票でき、最多得票者の次ターンAPが-3されるか。(同数時は全員対象)

## 2. 役職別スキル (1AP / 2AP)

### ネットワーク管理者
- [〇] **ログ追跡 (TRACE_LOG)** [1AP/Target]: 対象が現行ターンにハッカー/殺人犯行動をした場合 `POSITIVE` と出るか。(前ターンは対象外)
- [〇] **IPブロック (IP_BLOCK)** [2AP/Target]: 対象が次ターンにアクションを実行できなくなるか。

### セキュリティ分析官
- [〇] **パッチ適用 (PATCH)** [1AP/Target]: 対象への次ターンのデバフ（IPブロック、DDOS、ロックアウト）が効かなくなるか。
- [〇] **ファイアウォール (FIREWALL)** [2AP]: 次のダメージ/漏洩/ロックアウトを1回完全に防げるか。

### DBエンジニア
- [〇] **マスキング (MASKING)** [1AP]: 次ターンの漏洩発生を軽減するか。
- [〇] **ハニーポット (HONEY_POT)** [2AP]: 次の「データ持ち出し」実行者を特定し、DBエンジニアに通知するか。

### システムオペレーター
- [〇] **リソース・デプロイメント (TRANSFER)** [1AP/Target]: 対象の次ターンのAPが+1されるか。（1ターン1回制限）
- [〇] **システム・リストア (RESTORE)** [2AP]: HP0時に自動で20回復するか。

### インフラリーダー
- [〇] **レプリケーション (SKILL_COPY)** [1AP]: 他者の1APスキルをランダムにコピー・使用でき、使用後に消費されるか。
- [〇] **スペックアップ (SPEC_UP)** [2AP]: HP上限が120に拡張され、2ターン持続するか。

### DevOps
- [〇] **CI/CDパイプライン (PIPELINE)** [1AP/Target]: **自分を含む**指定した対象が「証拠解析」を行うと、BOT機数が解析度にボーナス算入されるか。
- [〇] **解析ボット配備 (DEPLOY_BOT)** [2AP]: 毎ターン自動で解析を進めるBOTが設置され、最大3台まで稼働するか。**1ターン1回制限が機能しているか。**

## 3. 殺人犯スキル

- [〇] **証拠改ざん (TAMPER)** [1AP]: 解析率を-5%減少させ、実行者にハッカー痕跡を残すか。
- [〇] **サボタージュ (SABOTAGE)** [1AP]: システムHPを-5減少させ、ハッカー痕跡を残すか。
- [〇] **ロックアウト (LOCKOUT)** [2AP/Target]: 対象の次ターンのAPを-3にするか。
- [〇] **停電工作 (BLACKOUT)** [2AP]: 議論フェーズを短縮させるか。
- [〇] **ノード・デストラクション (PHYSICAL_DESTROY)** [1AP]: 既存の解析BOTを1台破壊できるか。
- [〇] **偽装工作 (FALSE_FLAG)** [1AP/Target]: 対象を `POSITIVE`（黒）として誤認させられるか。（ターン限定）

## 4. ハッカースキル

- [〇] **マルウェア (INJECT)** [2AP]: システムHPを-40減少させるか（1ターン1回制限、1回でボタン無効）。
- [〇] **持ち出し (EXFIL)** [1AP]: 漏洩率を+15%上昇させるか。（1ターン3回制限、3回でボタン無効）
- [〇] **痕跡消去 (COVER)** [1AP]: 自身のハッカー行動フラグ（現行・前ターン両方）を解除し、ハッカーにのみ通知されるか。
- [〇] **DDOS攻撃 (DDOS)** [1AP/Target]: 対象の次ターンのAPを-2させるか。
- [〇] **偽装工作 (FALSE_FLAG)** [1AP/Target]: 対象を `POSITIVE`（黒）として誤認させられるか。（ターン限定）
