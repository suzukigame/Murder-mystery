# Project Overview: SKY-MAGYCC JUDAS - The Judas Protocol
This document provides a comprehensive overview of the "SKY-MAGYCC JUDAS" project for AI consultation and future development planning.

## 1. Project Identity
- **Genre**: Cyberpunk-themed Asymmetric Murder Mystery
- **Core Concept**: A three-way conflict between **Employees** (detectives), a **Murderer** (traitor), and a **Hacker** (third-party infiltrator).
- **Core Loop**: Discussion (Real-time) -> Action (Turn-based AP spending) -> Resolution (Automated state update).

## 2. Technology Stack
- **Frontend**: React (TypeScript), Lucide-react (Icons), Socket.io-client.
- **Backend**: Node.js, Express, Socket.io (Real-time synchronization).
- **UI/UX**: Custom CSS (Neon/Cyberpunk aesthetic), Glassmorphism, Responsive design.
- **Data Management**: In-memory GameState with server-side authority.

## 3. Game State & Roles
### Role Distribution (6 Players)
| Role          | Count | Objectives                                                                      |
| :------------ | :---- | :------------------------------------------------------------------------------ |
| **Employees** | 4     | Identify both Murderer and Hacker. Complete Evidence Analysis (100%).           |
| **Murderer**  | 1     | Prevent Analysis (100%). Sabotage system HP. Evade detection in the final vote. |
| **Hacker**    | 1     | Achieve Data Leak (100%) or destroy system HP (0).                              |

### Unique Skills (AP System)
Each of the 6 characters has a unique role (Admin, Analyst, DB Engineer, SysOp, Infra Lead, DevOps) with 1AP (Utility) and 2AP (Ultimate) skills.
- **Innovative Mechanic**: **CI/CD Pipeline** (DevOps skill) - Requires cooperation between two players to grant a bonus, encouraging strategic alliances.
- **Stealth Mechanics**: **FALSE_FLAG** (Misleading logs) and **COVER_TRACKS** (Clearing footprints).
