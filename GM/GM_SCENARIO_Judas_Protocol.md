# GM用進行ガイド: NEXUS_WAR - The Judas Protocol (Revised)

このドキュメントは、GMが「殺人犯（物理）」と「ハッカー（電脳）」の二重の脅威を管理し、プレイヤーに最高のミステリー体験を提供するための秘密指針です。

---

## 1. 真相と世界観
**【背景】**
主任開発者の「佐々木」は完璧主義であり、チーム全員の不正や過去の汚点を密かに調査していた。本日 18:00、彼は全員を会議室に集め、「明日の朝、全員を解雇し、警察に通報する」と宣言した。

**【事件の発生】**
その数時間後、サーバー室で佐々木の絞殺死体が発見される。同時に、システムのセキュリティが壊滅し、ランサムウェアによるデータ流出が開始された。

**【二重の脅威構造】**
1.  **殺人犯 (The Murderer)**: 6人の中の一人。佐々木を物理的に殺害した。動機は「秘密を守り、職を失わないため」。
2.  **ハッカー (The Hackers)**: サーバーがランダムに割り当てる2名。佐々木の死による混乱を「絶好のチャンス」と捉え、外敵と通じてデータを盗み出そうとしている。
    *   *注: 殺人犯がハッカーである場合もあれば、防衛側（殺人犯だがシステムは守りたい）である場合もあります。*

## 2. 登場人物の「秘密」と「動機」
全員が佐々木から「解雇宣告」を受けています。

| キャラクター         | 佐々木に握られた「秘密」               | 共通の動機                                   |
| :------------------- | :------------------------------------- | :------------------------------------------- |
| **Network Admin**    | サーバーをマイニングに私用していた。   | 秘密が守られれば職に残れる。                 |
| **Security Analyst** | 社内政治での更迭工作の証拠。           | 佐々木さえいなければ出世できる。             |
| **DB Engineer**      | 借金返済のためのデータ横流し未遂。     | 佐々木に全データをロックされていた。         |
| **Sys Operator**     | 過去のミスとログ改ざんの原本。         | バレれば業界から追放される。                 |
| **Infra Lead**       | 競合への引き抜きと機密持ち出しの契約。 | 佐々木が移籍の最大の障害だった。             |
| **Dev Ops**          | 不正アクセス用のバックドアの設置。     | 監査プログラムでバックドアがバレそうだった。 |

## 3. 推理の対立軸
プレイヤーは議論フェーズ（投票）において、以下の2点を特定しなければなりません。

*   **「ハッカーは誰か？」**: AP不一致（Actual Load の過多）と、チャットの不審な動きから特定する。
*   **「殺人犯は誰か？」**: 議論の中で「アリバイ」の矛盾や、「佐々木との最後の接触」を追及して特定する。

## 4. 勝利条件の整理
*   **防衛側 (かつ無実のPL)**: ハッカー2名の隔離に成功し、かつ殺人犯を特定（投票で追放）する。
*   **ハッカー**: データの100%抽出、またはシステムHPの0化。同時に、自分が殺人犯だと疑われないように立ち回る。
*   **殺人犯**: 自分が追放（投票）されずに、ゲームを終了させる。

## 5. GMの進行アドバイス
*   **「AP不一致」の提示**: ターンの終わりに「不自然な負荷」があることを強調し、ハッカーの存在を意識させてください。
*   **「ダイイングメッセージ」の追加（オプション）**: 議論が停滞したら、「佐々木の手に、誰かの社員証のストラップの一部が握られていた」などのヒントを追加しても構いません。
