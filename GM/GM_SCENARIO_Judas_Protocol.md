# GM用進行ガイド: NEXUS_WAR - The Judas Protocol (Revised v2)

このドキュメントは、GMが「殺人犯（証拠隠滅）」と「ハッカー（データ漏洩）」の対立構造を管理するための指針です。

---

## 1. 真相と世界観
**【背景】**
主任開発者の「鈴木」は、チーム全員を呼び出し「みんなに話さなければならないことがある。明日の朝一番に集まってくれ」と告げました。チームの誰もが、彼が密かに作成していた「極秘ファイル」——全員の不正（裏金、情報漏洩、私的流用など）を記録したもの——を公表するつもりだと確信し、恐怖に陥りました。

**【事件の発生】**
18:00、鈴木がサーバー室で何者かに殺害されました。
同時に、何者かがシステムに侵入し、外部へのデータ送信（LEAK）を開始しました。

**【二重の脅威構造】**
1.  **殺人犯 (The Murderer)**: 
    *   **人数**: 1名 (ランダム)。
    *   **目的**: 鈴木が残した「証拠ファイル」の解析（Evidence Analysis）を100%にさせないこと。解析が完了すると犯人が特定され、敗北します。
2.  **ハッカー (The Hacker)**: 
    *   **人数**: 1名 (ランダム)。
    *   **目的**: データの100%抽出 (LEAK)、またはシステム破壊 (HP 0)。
3.  **社員 (Employees)**:
    *   **人数**: 4名。
    *   **目的**: 殺人犯を特定すること（解析100%）。ただし、その前にハッカーにシステムを破壊（HP 0）されたり、データを全て盗まれたり（LEAK 100%）してはならない。

## 2. 役割とアクション (Roles & Actions)
ゲーム開始時に、以下の6つの役割がプレイヤーにランダムに割り振られます。キャラクター(名前)と役割は固定されていません。

### 2.1. 基本アクション (全員共通)
全てのプレイヤーが実行可能なアクションです。

| アクション名         | コスト | 効果                             | 備考                                   |
| :------------------- | :----- | :------------------------------- | :------------------------------------- |
| **解析 (ANALYZE)**   | 2 AP   | 証拠解析(Analysis) +10%          | 勝利条件(100%)に向けた主要アクション。 |
| **修復 (RESTORE)**   | 2 AP   | システムHP +10 回復              | ハッカーの攻撃(INJECT)に対抗する手段。 |
| **暗号化 (ENCRYPT)** | 2 AP   | データ漏洩(LEAK) -10%            | ハッカーの抽出(EXFIL)に対抗する手段。  |
| **監査 (AUDIT)**     | 1 AP   | 直前ターンの隠密行動の内訳を検知 | 実行者のみが結果を確認できる。         |

### 2.2. 固有スキル (Role Specific)
割り振られた役割によって使用可能になる強力なスキルです。

| 役割名                   | スキル名 (ID)   | 効果の詳細                                                                                     |
| :----------------------- | :-------------- | :--------------------------------------------------------------------------------------------- |
| **ネットワーク管理者**   | `TRACE_LOG`     | 指定ターゲットの昨ターンのハッカー行動を調査(Positive/Negative)。※`FALSE_FLAG`の影響を受ける。 |
| **セキュリティ分析官**   | `FIREWALL`      | 次のターン、システム(HP)へのダメージや漏洩、サボタージュを1回無効化する。                      |
| **DBエンジニア**         | `DATA_RECOVERY` | データ漏洩(LEAK)の進行度を **15%** 減少させる。                                                |
| **システムオペレーター** | `SYS_ROLLBACK`  | システム(HP)を **25** 回復させる。                                                             |
| **インフラリーダー**     | `SERVER_BOOST`  | 次のターンの証拠解析(Analysis)の進行度を **+15%** 加算する。                                   |
| **DevOps**               | `DEPLOY_BOT`    | 自動解析ボットを設置(最大3台)。ターン終了時に Analysis が **+3% x 台数** 自動進行する。        |

### 2.3. 隠密スキル (ハッカー & 殺人犯 専用)
ハッカーと殺人犯だけが使用できる、正体を隠しながら実行する特殊アクションです。

#### ハッカー
| スキル名 (ID)               | コスト | 効果                                                   |
| :-------------------------- | :----- | :----------------------------------------------------- |
| **マルウェア** (`INJECT`)   | 2 AP   | システム(HP)を **40** 減少させる。                     |
| **持ち出し** (`EXFIL`)      | 1 AP   | データ漏洩(LEAK)を **15%** 進行させる。                |
| **痕跡消去** (`COVER`)      | 1 AP   | 自身の行動痕跡を消去し、ログ追跡を回避(Negative)する。 |
| **DDOS攻撃** (`DDOS`)       | 1 AP   | ターゲットの次ターンのAPを **-2** する。               |
| **偽装工作** (`FALSE_FLAG`) | 1 AP   | ターゲットを偽装し、ログ追跡の結果を「陽性」に変える。 |

#### 殺人犯
| スキル名 (ID)                 | コスト | 効果                                                                       |
| :---------------------------- | :----- | :------------------------------------------------------------------------- |
| **証拠改ざん** (`TAMPER`)     | 1 AP   | 証拠解析(Analysis)を **5%** 減少させる。痕跡が残る。                       |
| **サボタージュ** (`SABOTAGE`) | 1 AP   | システム(HP)を **5** 減少させる。痕跡が残る。                              |
| **ロックアウト** (`LOCKOUT`)  | 2 AP   | ターゲットをロックアウトし、次ターンのAPを **0 (-3)** にする。痕跡が残る。 |
| **偽装工作** (`FALSE_FLAG`)   | 1 AP   | ターゲットを偽装し、ログ追跡の結果を「陽性」に変える。                     |


## 3. スキル使用のルール
*   **使用回数**: 各プレイヤーは1ターンに1回、自身のスキルを使用するか「通常行動」を選択できます。
*   **ログの不一致**: ハッカーアクションを実行してもAP消費ログが 0 と表示されるため（自分以外）、実際のシステム負荷との乖離からハッカーの存在を推測できます。
*   **殺人犯による妨害**: 殺人犯が通常の「解析」等を行うふりをして実際には加算しないサボタージュが可能です。

## 4. ゲームの流れと勝利条件
*   **フェーズ進行**: 議論フェーズ (Discussion) -> アクションフェーズ (Action) -> 判定/解決フェーズ (Resolve)
*   **勝利条件**:
    *   **社員勝利**: 証拠解析 (Analysis) 100% 達成。 **かつ**、ハッカーに勝利条件（HP 0 または LEAK 100%）を達成されていないこと。
    *   **ハッカー勝利**: データ漏洩 (LEAK) 100% または システムHP 0。
    *   **殺人犯勝利**: 8ターン終了時までに 証拠解析 100% を阻止する。あるいはハッカー勝利に便乗する（生存が条件）。

## 5. GMの進行アドバイス
*   **「進まない解析」**: 解析役（インフラリーダーやDevOps）が犯人の場合、解析ゲージが進みません。これを「不具合」ではなく「サボタージュ」としてPLに気づかせてください。
*   **「キーマンの隔離」**: 怪しい人物を投票で隔離すると、そのスキルが使えなくなります。犯人を隔離できれば妨害は止まりますが、貴重な戦力も失います。
*   **「ハッカーの存在を隠す」**: ゲーム開始時、PLには「殺人犯がいる」ことだけを伝え、「ハッカー」が含まれていることは伏せておくとよりスリリングになります。
*   **「公開のタイミング」**: 漏洩(LEAK)が30%〜40%を超えたあたりや、HPが大きく減少したタイミングで、「どうやら犯人とは別に、システムを乗っ取ろうとしている第3の勢力が潜んでいるようだ」とGMから情報を出すと、議論がより白熱します。
