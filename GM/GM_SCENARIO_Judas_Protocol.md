# GM用進行ガイド: NEXUS_WAR - The Judas Protocol (Revised v2)

このドキュメントは、GMが「殺人犯（証拠隠滅）」と「ハッカー（データ漏洩）」の対立構造を管理するための指針です。

---

## 1. 真相と世界観
**【背景】**
主任開発者の「佐々木」は、チーム全員の不正（裏金、情報漏洩、私的流用など）を記録した「極秘ファイル」を作成し、明日朝一番に警察へ提出すると脅迫を行いました。

**【事件の発生】**
18:00、佐々木がサーバー室で何者かに殺害されました。
同時に、何者かがシステムに侵入し、外部へのデータ送信（LEAK）を開始しました。

**【二重の脅威構造】**
1.  **殺人犯 (The Murderer)**: 
    *   **人数**: 1名 (ランダム)。
    *   **目的**: 佐々木が残した「証拠ファイル」の解析（Evidence Analysis）を100%にさせないこと。解析が完了すると犯人が特定され、敗北します。
2.  **ハッカー (The Hacker)**: 
    *   **人数**: 1名 (ランダム)。
    *   **目的**: データの100%抽出 (LEAK)、またはシステム破壊 (HP 0)。
3.  **市民 (Citizens)**:
    *   **人数**: 4名。
    *   **目的**: ハッカーの攻撃を凌ぎきり、かつ「証拠解析」を100%に進めて殺人犯を特定すること。

**【重要: アリバイと所在】**
全員、18:00前後に「空白の時間」があります。誰が犯人になってもおかしくない状況です。

## 2. 登場人物の「秘密」と「動機」
全員が **「証拠ファイルを解析されたくない」** という動機を持っていますが、殺人犯だけは **「殺人の証拠」** が含まれているため、必死に解析を止めようとします。

| キャラクター         | 表向きの役割 | スキル (New!) | 役割概要                                       |
| :------------------- | :----------- | :------------ | :--------------------------------------------- |
| **Network Admin**    | 捜査         | `TRACE_LOG`   | ハッカー行動の検知（捜査官）。                 |
| **Security Analyst** | 防衛         | `FIREWALL`    | ダメージ無効化（タンク）。                     |
| **DB Engineer**      | 防衛         | `RECOVERY`    | LEAK回復（ヒーラー）。                         |
| **Sys Operator**     | 防衛         | `ROLLBACK`    | HP大回復（ヒーラー）。                         |
| **Infra Lead**       | 解析         | `BOOST`       | **解析進行の要**。彼が犯人だと解析が進まない。 |
| **Dev Ops**          | 支援         | `DEPLOY_BOT`  | 自動解析ボット設置。長期戦で有利。             |

## 3. ゲームの流れと勝利条件
*   **フェーズ進行**: Discussion (会話) -> Action (行動選択) -> Resolve (判定)
*   **勝利条件**:
    *   **市民勝利**: Evidence Analysis 100% 達成。 (ハッカー勝利条件を満たされる前に)
    *   **ハッカー勝利**: LEAK 100% または HP 0。
    *   **殺人犯勝利**: 8ターン終了時までに Analysis 100% を阻止する。あるいはハッカー勝利に便乗する（生存が条件）。

## 4. GMの進行アドバイス
*   **「進まない解析」**: 解析役（Infra LeadやDev Ops）が犯人の場合、解析ゲージが進みません。これを「不具合」ではなく「サボタージュ」としてPLに気づかせてください。
*   **「キーマンの隔離」**: 怪しい人物を投票で隔離すると、そのスキルが使えなくなります。犯人を隔離できれば妨害は止まりますが、貴重な戦力も失います。
