# アクションログ仕様一覧

## 凡例
- **公開ログ**: 全プレイヤーのシステムログに表示されるメッセージ。
- **非公開ログ**: 自分、または対象プレイヤーだけに表示されるメッセージ。
- **匿名性**: 多くの公開ログは実行者名を含みませんが、**監査**など一部のアクションは実行者名が表示されます。

## 基本アクション (共通)

| アクション名                         | 区分 | 公開ログ (全員に見える)                                                     | 非公開ログ (自分/対象のみ)                                                     |
| :----------------------------------- | :--- | :-------------------------------------------------------------------------- | :----------------------------------------------------------------------------- |
| **システム修復**<br>(Restore System) | 防衛 | `システムパッチ適用。HP回復。`                                              | なし                                                                           |
| **証拠解析**<br>(Analyze Evidence)   | 防衛 | `証拠解析完了 (+10%)。`                                                     | なし                                                                           |
| **データ暗号化**<br>(Encrypt Data)   | 防衛 | `データ暗号化完了。漏洩リスク低減。`                                        | なし                                                                           |
| **監査**<br>(Audit Log)              | 特殊 | `[実行者名] がシステム監査を実行。結果はエージェントにのみ通知されました。` | **(自分)** `[監査報告] 前サイクルにおける不正タスク: X件 (侵入: Y, 改ざん: Z)` |

## ハッカーアクション (Hacker)

| アクション名                       | 効果         | 公開ログ (全員に見える)                                          | 非公開ログ (自分/対象のみ)                                                 |
| :--------------------------------- | :----------- | :--------------------------------------------------------------- | :------------------------------------------------------------------------- |
| **マルウェア**<br>(Inject Malware) | HP大ダメージ | `緊急警報: マルウェア検知。送信元: [暗号化済]。システムHP低下。` | なし                                                                       |
| **データ持ち出し**<br>(Exfiltrate) | 漏洩率上昇   | `データ持ち出し検知。送信元: [不明]。`                           | なし                                                                       |
| **痕跡消去**<br>(Cover Tracks)     | ログ消去     | `ログ消去を検知。システム痕跡が削除されました。`                 | なし                                                                       |
| **DDOS攻撃**<br>(DDOS)             | AP減少       | `警告: ネットワーク上の異常なリソース消費を検知。`               | **(対象)** `あなたの端末がDDOS攻撃を受けました。次ターンのAP -2。`         |
| **偽装工作**<br>(False Flag)       | ログ偽装     | **なし** (完全に隠密)                                            | **(自分)** `[対象] に偽装工作を実行。ログ追跡の結果はPOSITIVEとなります。` |

## 殺人犯アクション (Murderer)

| アクション名                        | 効果           | 公開ログ (全員に見える)                                                                                                                | 非公開ログ (自分/対象のみ)                                                 |
| :---------------------------------- | :------------- | :------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------- |
| **証拠改ざん**<br>(Tamper Evidence) | 解析進行度低下 | `警告: 証拠ログのデータ破損を検知。`                                                                                                   | なし                                                                       |
| **サボタージュ**<br>(Sabotage)      | HP小ダメージ   | `システムグリッチ検知。内部サボタージュの疑いあり。`<br>(防御時: `サボタージュ試行を検知。ファイアウォールによりブロックされました。`) | なし                                                                       |
| **ロックアウト**<br>(Lockout)       | 行動不能       | `端末に対するセキュリティロックアウトを開始。`                                                                                         | **(対象)** `あなたの端末はロックアウトされました。次ターンのAP -3。`       |
| **偽装工作**<br>(False Flag)        | ログ偽装       | **なし** (完全に隠密)                                                                                                                  | **(自分)** `[対象] に偽装工作を実行。ログ追跡の結果はPOSITIVEとなります。` |

## 固有スキル (Role Specific)

| 役割 / アクション                         | 公開ログ (全員に見える)                                         | 非公開ログ (自分/対象のみ)             |
| :---------------------------------------- | :-------------------------------------------------------------- | :------------------------------------- |
| **NwAdmin: ログ追跡**<br>(Trace Log)      | `[対象] に対するログ追跡を実行。結果は管理者に通知されました。` | **(自分)** `[対象] の追跡結果: [結果]` |
| **SecAnalyst: FW**<br>(Firewall)          | `ファイアウォール展開。次の攻撃を無効化します。`                | なし                                   |
| **DBEng: データ復旧**<br>(Data Recovery)  | `データ復旧完了。漏洩率が15%低下しました。`                     | なし                                   |
| **SysOp: ロールバック**<br>(Sys Rollback) | `システムロールバック実行。システムHP大回復 (+25)。`            | なし                                   |
| **Infra: ブースト**<br>(Server Boost)     | `サーバリソースブースト。解析効率向上 (+15%)。`                 | なし                                   |
| **DevOps: BOT配備**<br>(Deploy Bot)       | `自動セキュリティBOT配備完了。解析スループット向上。`           | なし                                   |
