# 社員スキル対応表 (1AP & 2AP 案・改)

各役割に「低コスト(1AP)」と「必殺技(2AP)」の2種類を割り当てた一覧表です。

| 役割名                                        | 1 AP スキル (汎用・調査・遅延)      | 効果                                                                                                                                         | 2 AP スキル (必殺・防御・逆転)             | 効果                                                                                      |
| :-------------------------------------------- | :---------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------- | :---------------------------------------------------------------------------------------- |
| **ネットワーク管理者**<br>(Network Admin)     | **ログ追跡**<br>`TRACE_LOG`         | 指定した対象の「昨ターンのハッカー行動」の有無(白/黒)を調査する。                                                                            | **通信遮断**<br>`IP_BLOCK`                 | 指定した対象1名の、次のターンの**すべてのアクション**を無効化する。                       |
| **セキュリティ分析官**<br>(Security Analyst)  | **セキュリティパッチ**<br>`PATCH`   | **事前にプレイヤーを選択**し、そのターンに指定した味方1名への「AP減少デバフ(DDOS/ロックアウト)」を無効化する。                               | **ファイアウォール**<br>`FIREWALL`         | 次ターン、システムへの「HPダメージ」と「LEAK進行」を、**最初の1回だけ**完全に無効化する。 |
| **DBエンジニア**<br>(Database Engineer)       | **データマスキング**<br>`MASKING`   | 次ターン、LEAK(情報漏洩)の進行を **-5%** 遅らせる。                                                                                          | **ハニーポット**<br>`HONEY_POT`            | 罠を張る。次ターン「データ持ち出し(EXFIL)」を行った実行者の名前を検知する。               |
| **システムオペレーター**<br>(System Operator) | **リソース譲渡**<br>`TRANSFER`      | 指定した味方1名の次ターンのAPを **+1** チャージする。<br>(自分のAPを分け与える支援スキル)                                                    | **緊急再起動**<br>`FORCE_REBOOT`           | システムHPを **+20** 回復するが、全員のAPが -1 される。<br>(緊急時のHP確保)               |
| **インフラリーダー**<br>(Infra Lead)          | **負荷分散**<br>`LOAD_BALANCER`     | 次ターン、システムHPへのダメージを**半減**する。その代わり、ダメージ発生時、**全員のAPが -1** される。<br>(サーバー負荷を全員のAP負荷に変換) | **オーバークロック**<br>`SERVER_OVERCLOCK` | 次ターン、全員の「解析」効率を **1.5倍** にする。<br>(ただし被ダメージも1.5倍)            |
| **DevOps**<br>(Development & Operations)      | **CI/CDパイプライン**<br>`PIPELINE` | **味方1名を選択**。自分と相手の解析効率を次ターンに+5%ずつ上昇させる（自動処理）。                                                           | **解析ボット配備**<br>`DEPLOY_BOT`         | 自動解析ボットを設置(最大3台)。毎ターン自動で解析を進めるBOTを1台配備できる。             |

- **負荷分散**: ダメージが発生しなかった場合、AP減少は起こりません。攻撃が来そうなタイミングで使うカウンター防御です。

# スキル検証チェックリスト

全スキルの動作が仕様通りか、以下の項目に従って検証を行います。

## 1. 共通アクション

- [ ] **証拠解析 (ANALYZE_EVIDENCE)**: 解析率が上昇するか。殺人犯が実行しても上昇しないか（仕様要確認）。
- [ ] **システム修復 (RESTORE_SYSTEM)**: システムHPが+10%回復するか。
- [ ] **データ暗号化 (ENCRYPT_DATA)**: 漏洩率が-10%減少するか。
- [ ] **監査ログ参照 (VIEW_AUDIT_LOG)**: 前ターンのハッカー行動数が実行者にのみ通知されるか。

## 2. 役職別スキル (1AP / 2AP)

### ネットワーク管理者
- [ ] **ログ追跡 (TRACE_LOG)** [1AP/Target]: 対象が前ターンまたは今ターンにハッカー/殺人犯行動をした場合 `POSITIVE` と出るか。
- [ ] **IPブロック (IP_BLOCK)** [2AP/Target]: 対象が次ターンにアクションを実行できなくなるか。

### セキュリティ分析官
- [ ] **パッチ適用 (PATCH)** [1AP/Target]: 対象への次ターンのデバフ（IPブロック、DDOS、隔離）が効かなくなるか。
- [ ] **ファイアウォール (FIREWALL)** [2AP]: 次の「マルウェア注入」「データ持ち出し」「サボタージュ」を1回防げるか。

### DBエンジニア
- [ ] **マスキング (MASKING)** [1AP]: 漏洩率を-5%減少させるか（暗号化より弱いが低コスト）。
- [ ] **ハニーポット (HONEY_POT)** [2AP]: 次の「データ持ち出し」実行者を特定し、DBエンジニアに通知するか。

### システムオペレーター
- [ ] **リソース譲渡 (TRANSFER)** [1AP/Target]: 対象の次ターンのAPが実質+1されるか（消費分をマイナス）。
- [ ] **強制再起動 (FORCE_REBOOT)** [2AP]: HP+20%回復し、副作用として全プレイヤーのAPが-1されるか。

### インフラリーダー
- [ ] **負荷分散 (LOAD_BALANCER)** [1AP]: 次のハッカー攻撃のダメージを半減させるか。副作用として全プレイヤーのAPが-1されるか。
- [ ] **オーバークロック (SERVER_OVERCLOCK)** [2AP]: 次ターンの解析速度が1.5倍になる。ただしHPダメージも1.5倍になるか。

### DevOps
- [ ] **CI/CDパイプライン (PIPELINE)** [1AP/Target]: 自分と対象の解析速度が次ターンに+5%ずつ上昇するか（自動処理）。
- [ ] **解析BOT配備 (DEPLOY_BOT)** [2AP]: 毎ターン自動で解析を進めるBOTを1台配備できるか（最大3台）。

## 3. 殺人犯スキル

- [ ] **証拠改ざん (TAMPER_EVIDENCE)** [1AP]: 解析率を-5%減少させ、実行者にハッカー痕跡を残すか。
- [ ] **サボタージュ (SABOTAGE)** [1AP]: システムHPを-5%減少させ、ハッカー痕跡を残すか。
- [ ] **ロックアウト (LOCKOUT)** [2AP/Target]: 対象の次ターンのAPを-3（実質0）にするか。
- [ ] **停電工作 (BLACKOUT)** [2AP]: 次ターンの議論時間が50%に短縮されるか。
- [ ] **物理破壊 (PHYSICAL_DESTROY)** [2AP]: 既存の解析BOTを1台破壊できるか。

## 4. ハッカースキル

- [ ] **マルウェア注入 (INJECT_MALWARE)** [2AP]: システムHPを-40%（オーバークロック時は1.5倍）減少させるか。
- [ ] **データ持ち出し (EXFILTRATE)** [1AP]: 漏洩率を+15%上昇させるか。
- [ ] **痕跡消去 (COVER_TRACKS)** [1AP]: 自身のハッカー行動フラグを解除し、追跡を回避できるか。
- [ ] **DDOS攻撃 (DDOS)** [1AP/Target]: 対象の次ターンのAPを-2させるか。
- [ ] **偽装工作 (FALSE_FLAG)** [1AP/Target]: 対象を `POSITIVE`（黒）としてログに残し、追跡を攪乱できるか。
