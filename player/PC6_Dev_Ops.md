# Character Sheet: Dev Ops (WATANABE)

[PROFILE]
名前: 渡辺
役職: デブオプス
背景: 効率化を愛するスピード狂。

[SECRET] (佐々木に握られた秘密)
「あなたは自分専用のバックドアを仕込み、開発リソースを外部の友人たちの遊び場に貸し出していた。佐々木は本日、そのバックドアを完全に閉鎖し、あなたの全権限を剥奪する処理を開始した。」

[MOTIVE] (殺害の動機)
権限がなくなれば、友人たちとの「取引」も終わりだ。佐々木がいなくなれば、処理が完了する前に権限を奪い返せるかもしれない。

---

[SPECIAL STATUS] (このシートを受け取ったあなたへ)
あなたは今回、**「佐々木を殺した犯人」ではありません。**
しかし、もともと「バックドア」を持っていたあなたは、誰よりもハッカーとして疑われやすい立場にあります。

[GOAL]
1.  (共通) ハッカーを特定し、システムを守り抜く。
2.  (個人) 自分の「バックドア」の知識を逆手に取り、誰が最も効率的にハッキングを行っているか（ハッカーの特定）を論理的に語ることで、味方だと信じ込ませる。
