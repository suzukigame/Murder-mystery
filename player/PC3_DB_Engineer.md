# Character Sheet: DB Engineer (SUZUKI)

## 👤 プロフィール
*   **名前**: 鈴木（SUZUKI）
*   **役職**: データベースエンジニア (DB Engineer)
*   **バックグラウンド**: 膨大なデータを管理する「鍵師」。丁寧な仕事ぶりで信頼されているが、最近、顔色が悪い。

## 🗝 秘匿データ (Secret)
**「多額の個人的な借金があり、機密データを外部のブローカーに売却することを検討していた。」**

## 🩸 殺人事件の動機
ギャンブルで作った多額の借金が膨れ上がり、逃げ場を失っている。AI「NEXUS」のコアデータの一部を抜き出し、闇市場に売却すれば借金は一瞬で帳消しになる。しかし、佐々木主任が導入した最新の監視システムがそれを阻んでいた。主任がいなければ、データへのアクセスは遥かに容易になるはずだ。

## 🎯 勝利条件
*   **共通**: ハッカーを特定し、AI「NEXUS」のシステムを守り抜く。
*   **個人**: 誰よりも早く「データ流出 (Leak)」の形跡を察知し、自分の関与を疑われないように立ち回る。
