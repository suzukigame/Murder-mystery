# Character Sheet: Security Analyst (NIHEI)

[PROFILE]
名前: 二瓶
役職: セキュリティアナリスト
背景: 脆弱性診断のエキスパート。他人のミスに厳しい。

[SECRET] (鈴木に握られた秘密)
鈴木から「チームのみんなに話さなければならないことがある。明日の朝、集まってくれ」と告げられた。あなたは、彼があなたの不正（彼を追い落とすための偽造文書作成）が記録された「極秘ファイル」を公表するつもりだと確信している。

[MOTIVE] (殺害の動機)
鈴木がいれば破滅する。彼が死に、証拠ファイルさえ消えれば、あなたは助かる。

---

[SPECIAL STATUS] (このシートを受け取ったあなたへ)
**あなたの運命（役職）は、ゲーム開始時にシステムから通知されます。**

1.  **もしあなたが【社員】なら**:
    *   あなたは犯人ではありません。
    *   **目的**: 自身のスキル `FIREWALL` でシステムを守り、**証拠解析(Evidence Analysis)を100%に進めて** 殺人犯を暴いてください。

2.  **もしあなたが【殺人犯】なら**:
    *   あなたは18:00、サーバー室で鈴木を絞殺しました。
    *   **目的**: **証拠解析が100%になるのを阻止** してください。解析完了＝逮捕です。

3.  **もしあなたが【ハッカー】なら**:
    *   あなたは鈴木の死に乗じてシステムに侵入しました。
    *   **目的**: **データ漏洩(LEAK)を100%にする** か、システムを破壊(HP 0)してください。

[GOAL]
画面上の `Secret Intel` ボックスに表示されるあなたの「真の役割」に従って行動してください。
